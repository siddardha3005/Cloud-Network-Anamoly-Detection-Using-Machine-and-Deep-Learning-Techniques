# Cloud-Network-Anamoly-Detection-Using-Machine-and-Deep-Learning-Techniques

# Introduction
Cloud computing represents a transformative paradigm within the field of computing,
enabling the storage, management, and processing of data through interconnected remote
servers accessed via the Internet. Unlike traditional computing models that rely on localized
hardware and on-premise servers, cloud networks leverage a globally distributed
infrastructure of data centers that provide scalable, on-demand resources. This shift from
hardware-dependent systems to a resource-rich, interconnected architecture has become a
defining characteristic of the modern technological landscape.
# major Highlights
Machine Learning Classification: Implemented multiple ML algorithms, including Support Vector Machine (SVM), Logistic Regression, and Gradient Boosting, to identify network anomalies.

Data Preprocessing: Processed network activity data and used Label Encoding and a 70:30 training/testing split.

Feature Analysis: Analyzed 10 network activity indicators, including failed login attempts, login frequency, data transfers, IP location changes, malware detections and suspicious URL clicks.

Ensemble Learning: Combined multiple classifiers using a Voting Classifier to generate anomaly predictions.

Model Evaluation: Evaluated models using accuracy, precision, recall, F1-score and confusion matrices.

Web Application Development: Developed a Django-based application with user registration, login, anomaly prediction and result visualization.

Data Visualization: Displayed model accuracy and prediction results through graphical dashboards.
